# Evidence-driven controller: generated tables (M6.1)

Generated by `ee-ctl simulate` / `ee-ctl prior-curve` over the fresh frozen-protocol real-model data `docs/evaluations/data/m61-*.json` (model gemini-2.5-flash). Protocol, verdict rule and acceptance criteria were committed before any held-out outcome was inspected: [design](../experiments/evidence-driven-controller-design.md). Narrative, caveats and the decision: [evidence-driven-controller-report.md](./evidence-driven-controller-report.md). Cells are `success / tokens per verified success`; the unit of inference is the task; one recorded draw per task and action; cell verdicts use the controller's contractual 10-point margin, A2 verdicts the M6 5-point margin.

Parameters (all runs): the frozen M6 defaults (n_min 30, min_total_verified 100, epsilon 0.10, min_cost_saving 10%, delta_low 0.10, Newcombe 95% one-sided) plus the frozen evidence parameters (n_min_pairs 30, drift_min_n 30, explore_target_cap 400); 20 seeded orders, seed 20260601, estimator republished every 10 tasks, warm rule-only log = M6 development set D2. Priors: V-timeout (238 paired tasks) and V-pool (60) never share tasks with H2.
